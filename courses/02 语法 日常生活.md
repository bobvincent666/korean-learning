## 一、아요／어요／해요：礼貌表达

### 1. 用法

`-아요 / -어요 / -해요` 接在动词或形容词词干后，构成日常生活中最常用的礼貌语气。

可以表示：

- 陈述：我去公司。
- 疑问：你去公司吗？
- 描述：天气很好。
- 日常请求或建议：请坐。／一起吃吧。

韩语通常不改变句子形式，而是通过语调或问号区分陈述和疑问：

- 회사에 가요.  
    去公司。
    
- 회사에 가요?  
    去公司吗？
    

### 2. 词干怎么找

去掉词典形中的 `다`，剩下的部分就是词干。

|词典形|中文|词干|
|---|---|---|
|가다|去|가|
|먹다|吃|먹|
|공부하다|学习|공부하|
|좋다|好|좋|

### 3. 变形规则

#### 规则一：最后一个元音是 ㅏ 或 ㅗ

接 `-아요`。

|原形|变化|中文|
|---|---|---|
|살다|살아요|生活、居住|
|앉다|앉아요|坐|
|좋다|좋아요|好|
|오다|와요|来|
|보다|봐요|看|

注意：

- `오 + 아요 → 와요`
- `보 + 아요 → 봐요`
- `가 + 아요 → 가요`

#### 规则二：其他元音

接 `-어요`。

|原形|变化|中文|
|---|---|---|
|먹다|먹어요|吃|
|읽다|읽어요|读|
|마시다|마셔요|喝|
|배우다|배워요|学习|
|쓰다|써요|写、使用|
|재미있다|재미있어요|有趣|

常见缩写：

- `마시 + 어요 → 마셔요`
- `배우 + 어요 → 배워요`
- `쓰 + 어요 → 써요`

#### 规则三：하다

`하다` 统一变成 `해요`。

|原形|变化|中文|
|---|---|---|
|하다|해요|做|
|공부하다|공부해요|学习|
|일하다|일해요|工作|
|운동하다|운동해요|运动|
|요리하다|요리해요|做饭|

### 4. 日常生活例句

- 저는 아침을 먹어요.  
    我吃早饭。
    
- 커피를 마셔요.  
    喝咖啡。
    
- 회사에서 일해요.  
    在公司工作。
    
- 저녁에 운동해요.  
    晚上运动。
    
- 한국어를 공부해요.  
    学习韩语。
    
- 오늘 날씨가 좋아요.  
    今天天气很好。
    
- 지금 바빠요?  
    现在忙吗？
    
- 매일 뉴스를 봐요.  
    每天看新闻。

## 二、场所名词＋에 가요

### 1. 用法

助词 `에` 接在场所名词后，表示移动的目的地，相当于“去……”“到……”。

基本结构：

> 主语＋场所＋에＋가요

例如：

- 저는 회사에 가요.  
    我去公司。
    
- 친구가 학교에 가요.  
    朋友去学校。
    
- 어디에 가요?  
    去哪里？
    

### 2. 常和 에 搭配的移动动词

|表达|中文|
|---|---|
|장소에 가요|去某地|
|장소에 와요|来某地|
|장소에 다녀요|经常去、在某地上学或工作|
|장소에 도착해요|到达某地|
|장소에 들어가요|进入某地|

例句：

- 집에 가요.  
    回家。
    
- 한국에 와요.  
    来韩国。
    
- 매일 회사에 다녀요.  
    每天去公司上班。
    
- 공항에 도착해요.  
    到达机场。
    

### 3. 日常场所词汇

|韩语|中文|例句|
|---|---|---|
|집|家|집에 가요.|
|회사|公司|회사에 가요.|
|학교|学校|학교에 가요.|
|식당|餐厅|식당에 가요.|
|카페|咖啡店|카페에 가요.|
|편의점|便利店|편의점에 가요.|
|마트|超市|마트에 가요.|
|병원|医院|병원에 가요.|
|은행|银行|은행에 가요.|
|공항|机场|공항에 가요.|
|화장실|洗手间|화장실에 가요.|

### 4. 에 和 에서 的区别

这是初学者最容易混淆的地方。

|助词|作用|例句|
|---|---|---|
|에|移动的目的地|회사에 가요. 去公司。|
|에서|动作发生的场所|회사에서 일해요. 在公司工作。|

对比：

- 식당에 가요.  
    去餐厅。
    
- 식당에서 밥을 먹어요.  
    在餐厅吃饭。
    
- 카페에 가요.  
    去咖啡店。
    
- 카페에서 커피를 마셔요.  
    在咖啡店喝咖啡。

## 三、日常生活对话

### 对话一：上班

A：아침에 어디에 가요?  
早上去哪里？

B：회사에 가요.  
去公司。

A：회사에서 뭐 해요?  
在公司做什么？

B：일해요.  
工作。

### 对话二：吃午饭

A：점심에 어디에 가요?  
中午去哪里？

B：식당에 가요.  
去餐厅。

A：식당에서 뭐 먹어요?  
在餐厅吃什么？

B：비빔밥을 먹어요.  
吃拌饭。

### 对话三：下班后

A：퇴근 후에 뭐 해요?  
下班后做什么？

B：마트에 가요.  
去超市。

A：마트에서 뭐 사요?  
在超市买什么？

B：우유하고 과일을 사요.  
买牛奶和水果。

## 练习一：变成礼貌形式

把括号中的词变成 `-아요／-어요／-해요` 形式。

1. 저는 아침을 __________.（먹다）
2. 매일 한국어를 __________.（공부하다）
3. 친구가 집에 __________.（오다）
4. 저녁에 텔레비전을 __________.（보다）
5. 카페에서 커피를 __________.（마시다）
6. 회사에서 __________.（일하다）
7. 이 책은 재미__________.（있다）
8. 오늘 날씨가 __________.（좋다）
9. 편지를 __________.（쓰다）
10. 한국어를 __________.（배우다）

6. 마트___ 과일을 사요.

9. 식당___ 비빔밥을 먹어요.
