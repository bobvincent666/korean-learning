## 一、场所助词 `에서`

`에서` 接在场所名词后，表示“动作发生的地点”。

> 场所＋에서＋动作

|例句|中文|
|---|---|
|카페에서 친구를 만나요.|在咖啡店见朋友。|
|공원에서 운동해요.|在公园运动。|
|도서관에서 공부해요.|在图书馆学习。|
|집에서 책을 읽어요.|在家读书。|

简单区分：

- `에`：去哪里、在哪里  
    `학교에 가요.` 去学校。
- `에서`：在哪里做事情  
    `학교에서 공부해요.` 在学校学习。

## 二、过去时 `-았어요／-었어요／-했어요`

接在动词或形容词词干后，表示过去发生的事情。

### 变形规则

|词干最后的元音|规则|例子|
|---|---|---|
|`ㅏ、ㅗ`|`-았어요`|만나다 → 만났어요|
|其他元音|`-었어요`|먹다 → 먹었어요|
|`하다`|`-했어요`|공부하다 → 공부했어요|

### 图片中的动词

|原形|中文|过去时|
|---|---|---|
|보다|看|봤어요|
|읽다|读|읽었어요|
|듣다|听|들었어요|
|먹다|吃|먹었어요|
|마시다|喝|마셨어요|
|만나다|见面|만났어요|
|공부하다|学习|공부했어요|
|운동하다|运动|운동했어요|
|쓰다|写、使用|썼어요|

注意：`듣다 → 들었어요` 是不规则变化，需要单独记忆。

### 例句

- 어제 시장에서 우유를 샀어요.  
    昨天在市场买了牛奶。
    
- 투이 씨는 어제 책을 읽었어요.  
    翠昨天读书了。
    
- 치엔 씨는 음악을 들었어요.  
    倩听音乐了。

# 练习题

## 练习一：填写 `에` 或 `에서`

1. 저는 학교___ 가요.
2. 저는 학교___ 공부해요.
3. 친구를 카페___ 만났어요.
4. 어제 공원___ 운동했어요.
5. 유키 씨가 집___ 있어요.
6. 집___ 음악을 들었어요.

## 练习二：变成过去时

1. 보다 → __________
2. 먹다 → __________
3. 마시다 → __________
4. 만나다 → __________
5. 공부하다 → __________
6. 운동하다 → __________
7. 듣다 → __________
8. 쓰다 → __________

## 练习三：选择合适的动词

`읽었어요　마셨어요　만났어요　운동했어요　공부했어요`

1. 도서관에서 한국어를 __________.
2. 카페에서 친구를 __________.
3. 집에서 책을 __________.
4. 공원에서 __________.
5. 식당에서 물을 __________.

## 练习四：翻译

1. 我昨天在家读书了。
2. 我在咖啡店见了朋友。
3. 敏秀在公园运动了。
4. 我在图书馆学习了。
5. 我昨天听音乐了。
