# 零基础韩语课程站设计规格

## 目标

将现有韩语拼读页面整理为可部署到 GitHub Pages 的课程站。网站只展示韩语学习内容，并允许后续持续增加“第 01 课、第 02 课……”形式的语法课程。

## 标题与定位

- 网站名称：**零基础韩语课**
- 副标题：**从韩文字母、发音到日常语法与练习**
- 页面标题统一明确写出内容，不使用“语法一”等无法独立理解的名称。

现有三节语法课命名为：

1. 第 01 课｜礼貌表达与“去某地”
2. 第 02 课｜谁在哪里？主语与位置表达
3. 第 03 课｜在哪里做过什么？场所与过去时

## 页面结构

桌面端采用文档式三栏布局：

1. 顶部：网站标题和主导航。
2. 左侧：按“入门基础、日常语法、单词与句子、视频练习”分组的课程目录。
3. 中间：当前课程正文。
4. 右侧：当前课程内的简短目录。

移动端隐藏左右栏，顶部提供“课程目录”按钮；课程正文占满可用宽度。

## 导航

顶部只保留韩语内容：

- 课程首页
- 韩文字母
- 单词与句子
- 语法课程
- 视频学习

课程使用 GitHub Pages 兼容的哈希地址，例如 `#lesson-1`。刷新或分享该地址时仍打开对应课程，不依赖服务器路由。

## 课程内容格式

每节语法课统一包含：

1. 明确的课程编号与标题
2. “本课学什么”摘要
3. 简明语法规则
4. 日常例句
5. 练习题
6. 可展开的参考答案
7. 上一课／下一课

语法和练习保持短小，不扩展与当课无关的知识。

## 实现方式

保留现有纯 HTML、CSS 和 JavaScript，不迁移 VitePress，也不增加前端框架。课程内容集中存放为数据，左侧目录、正文和上下课导航由现有渲染方式生成。新增课程只增加课程数据，不复制页面框架。

现有拼读表、单词句子、视频、MP3 发音、速度选择和重复播放继续使用。所有静态资源使用相对路径，保证发布在 `/korean-learning/` 子路径时正常加载。

## GitHub Pages

目标地址为：

`https://bobvincent666.github.io/korean-learning/`

使用仓库 `main` 分支发布。站点不需要后端、数据库或云端语音服务。

## 错误与降级

- 无法加载预生成 MP3 时，继续使用现有浏览器韩语语音回退。
- 外部视频无法嵌入时，保留“打开原视频”链接。
- 无效课程哈希返回课程首页，不显示空白页。
- JavaScript 不可用时至少保留网站标题与基础说明。

## 验证标准

- 桌面端可以从左侧目录打开三节语法课。
- 手机端可以打开和关闭课程目录。
- 每节课的练习答案默认收起并可展开。
- 课程哈希可以刷新和分享。
- 拼读、单词句子、视频及现有音频功能不回归。
- GitHub Pages 子路径下的 HTML、CSS、JavaScript、manifest 和 MP3 均能加载。

## 暂不包含

- 用户账号、学习进度同步、后台管理和数据库。
- 全站搜索、多语言切换和深色模式。
- VitePress 或其他框架迁移。
